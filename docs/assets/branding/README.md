# Branding placeholders

Replace `logo.svg` and `favicon.svg` with the final artwork. The header logo
uses a square bounding box; leave space around the artwork inside its viewBox.
The site title remains text, so the mark does not need to contain a wordmark.

`social.png` is the temporary 1200 × 630 social preview. Replace it alongside
the final branding. All assets are served locally; no external fonts or image
services are required. Asset paths are configured in `zensical.toml` and
`website/overrides/main.html`.
